# 🏎️ Site sobre Fórmula 1

## 📖 Sobre o projeto

Este projeto consiste na criação de um site sobre a Fórmula 1, desenvolvido utilizando HTML5.

O objetivo do site é apresentar informações sobre a história da Fórmula 1, seus pilotos, equipes, circuitos, carros, regras, estratégias, bandeiras, classificação e campeonato.

O projeto foi desenvolvido como uma atividade de aprendizado de HTML, utilizando diferentes elementos para organizar e apresentar o conteúdo de forma estruturada.

---

## 🎯 Objetivo

O principal objetivo deste projeto é desenvolver um site com várias páginas relacionadas à Fórmula 1, colocando em prática conceitos de HTML, como:

- Estrutura básica de uma página HTML;
- Títulos e subtítulos;
- Parágrafos;
- Listas ordenadas e não ordenadas;
- Tabelas;
- Links entre páginas;
- Imagens;
- Vídeos;
- Áudios;
- Formulários;
- Elementos semânticos;
- Organização de conteúdo.
